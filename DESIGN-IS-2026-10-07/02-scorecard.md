# Dieter Rams scorecard

These are design-review judgments under the skill's strict 0–3 rubric, not a validated usability metric or conversion prediction. Evidence confidence is described in `01-evidence.md`; mobile and performance findings are source-based. Worst relevant instances govern each score.

1. **Innovative — 1/3.** Evidence: [E8](01-evidence.md#e8--pattern-originality-and-durability), familiar hero/cards/planner. No demonstrated differentiated interaction; no peer benchmark, so provisional conservative score.
2. **Useful — 1/3.** Evidence: [E2](01-evidence.md#e2--recommendation-accuracy), repair and quantity answers conflict with returned camera layouts; [E1](01-evidence.md#e1--purpose-and-primary-path), direct contact remains available. The worst planner route requires corrective discussion rather than giving relevant starting guidance.
3. **Aesthetic — 2/3.** Evidence: [E4](01-evidence.md#e4--visual-hierarchy-and-restraint), cohesive navy/cyan/Manrope desktop hero but tiny labels and secondary accent/style variation. A clear system exists; those two shortcomings prevent 3.
4. **Understandable — 1/3.** Evidence: [E3](01-evidence.md#e3--pricing-and-copy-honesty) and [E5](01-evidence.md#e5--mobile-navigation-and-accessibility), technical jargon, booking/enquiry mismatch, and missing mobile navigation. Multiple labels/routes need explanation despite a clear headline.
5. **Unobtrusive — 1/3.** Evidence: [E1](01-evidence.md#e1--purpose-and-primary-path), [E4](01-evidence.md#e4--visual-hierarchy-and-restraint), decorative console, floating controls and large adjacent-business promotion compete with the CCTV decision path. No interrupting modal merits avoiding 0.
6. **Honest — 1/3.** Evidence: [E2](01-evidence.md#e2--recommendation-accuracy), [E3](01-evidence.md#e3--pricing-and-copy-honesty), overstated tailoring and booking labels/complete-security claim. Strong price and handoff disclosures prevent a deceptive-flow score of 0; claim falsity is not assumed.
7. **Long-lasting — 2/3.** Evidence: [E8](01-evidence.md#e8--pattern-originality-and-durability), durable type/palette with one trend-sensitive glow/status-console motif. Core identity is worth retaining.
8. **Thorough — 2/3.** Evidence: [E6](01-evidence.md#e6--states-and-implementation-detail), six state categories exist but synchronous loading is rough/unverified. Strong inline validation supports 2; full interaction verification is incomplete.
9. **Environmentally friendly — 2/3.** Evidence: [E7](01-evidence.md#e7--weight-and-friction), 54,475 bytes initial local JS, no inferred idle loop and motion guard; explicit JS smooth-scroll guard is unresolved. Low weight and deferred map justify 2; all 3-point conditions have not been demonstrated.
10. **As little design as possible — 1/3.** Evidence: [E1](01-evidence.md#e1--purpose-and-primary-path), [E3](01-evidence.md#e3--pricing-and-copy-honesty), [E4](01-evidence.md#e4--visual-hierarchy-and-restraint). Five candidates for removal/consolidation are a duplicate full form, repeated package inclusions, decorative microcopy, large mid-flow sister-division panel, and repeated quote/benefit exposition. Purpose is still evident, so 0 is unwarranted.

**Total: 14/30. Verdict under this rubric: REDESIGN.**

This verdict scopes to homepage information architecture and enquiry/recommendation flow. It does not prescribe replacing the brand or rebuilding the stack. Actual conversion effects require customer/task testing after changes.
