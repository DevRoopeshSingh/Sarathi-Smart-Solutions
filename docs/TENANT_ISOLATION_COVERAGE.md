# Tenant isolation coverage — Milestone 2 audit

Audit baseline: before Milestone 2, every existing business query was global. Authentication alone does not constrain ownership. This audit covers the current source tree; it does not authorize additional organization onboarding.

| Area                           | Existing paths                                                           | Required organization boundary                                      | Division boundary                                            | Roles                                                   |
| ------------------------------ | ------------------------------------------------------------------------ | ------------------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| Customers                      | DAL list/create, options API, project picker, project counts             | Customer organization; referenced project ownership                 | Customers organization-wide; project counts restricted       | Admin/operator create, viewer read                      |
| Leads                          | List/search/dashboard/detail, create/status actions, conversion          | Lead organization and customer FK                                   | Assigned active divisions                                    | Admin/operator write; viewer read                       |
| Projects/services              | List/search/counts/dashboard/detail, create/stage actions, service array | Project/customer/lead composite ownership                           | Assigned active divisions; conversion retains lead division  | Admin/operator write; viewer read                       |
| History                        | Workflow activity, creation/stage audit inserts                          | Parent project organization; actor membership FK                    | Parent project division                                      | Project readers; authorized audited writes              |
| Quotations/items               | Lists/search/detail/activity; schema-only items                          | Parent project/customer organization                                | Parent project division                                      | Admin/operator/viewer read; no runtime financial writes |
| Payments                       | Lists/search; immutable records                                          | Parent project/quotation organization                               | Parent project division                                      | Admin/operator read; viewer denied; no runtime writes   |
| Products/costing/BOM           | Schema only, no runtime grants or routes                                 | Organization and parent/product composite FKs                       | Parent project for costing/BOM                               | Owner maintenance only                                  |
| Staff                          | List and role action, owner provisioning/recovery                        | Active current organization; no global role-change runtime function | Admin only; assignments owner-managed                        | Admin; operator/viewer denied                           |
| Memberships/divisions          | Context API, resolver, owner provisioning                                | Active authenticated membership; same-org assignment FKs            | Active assignments; organization admins all active divisions | Resolver checks existing permission intersection        |
| Identity/MFA/onboarding        | Auth/session/security APIs, per-user onboarding                          | Identity-owned; business access additionally requires membership    | Not applicable                                               | Existing identity/security rules retained               |
| Exports/files/delete/invite UI | No implementation                                                        | No new public access path                                           | Not applicable                                               | Unsupported; runtime delete grants absent               |

Migration approach: add ownership through metadata column defaults to preserve frozen quotation and append-only rows without UPDATE or trigger bypass. Verify backfill, enforce NOT NULL and composite FKs, replace global SKU/idempotency uniqueness with organization-scoped uniqueness, add scoped indexes, then replace seed defaults with required transaction-local context defaults. RLS fails closed outside a scoped transaction. Scope is revalidated on each connection and each statement; pooled tenant session state is never persistent. Existing owner tooling remains privileged and must select its organization explicitly.
