# Homepage SEO audit — 5 October 2026

Audited URL: https://sarathismartsolutions.in/

## Assessment

The live homepage has a sound technical foundation for indexing. No website can appear for every search or guarantee first position. Prioritize relevant CCTV searches in the actual service area. Google does not guarantee crawling, indexing, or displaying a compliant page: [Google’s explanation of Search](https://developers.google.com/search/docs/fundamentals/how-search-works/).

Public searches for the exact domain and business name/phone did not return a matching result in the search tool used for this audit. This is a discovery signal, not proof that Google has not indexed the site. Search Console is required to confirm Google’s indexing status, selected canonical, impressions, and rankings.

## Priority 1 — Confirm discovery and indexing

1. Verify a Domain property for `sarathismartsolutions.in` in Google Search Console using DNS, unless already verified.
2. Submit `https://sarathismartsolutions.in/sitemap.xml` once and check its processing result.
3. Inspect the homepage URL: check “URL is on Google,” crawl permission, fetched page, and Google-selected canonical. Run Test Live URL and request indexing after substantive updates.
4. Review Page Indexing, Security Issues, Manual Actions, and the Performance report. Search the query report for CCTV and the localities served. Record impressions, clicks, and enquiries as a baseline.

A sitemap helps discovery but does not guarantee indexing or ranking. [Google sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview), [Search Console guidance](https://developers.google.com/search/docs/monitor-debug/search-console-start).

## Priority 2 — Strengthen local business visibility

Verify and complete the existing Google Business Profile. The homepage links to a profile, but its verification status and management access were not checked.

Use the real business name, accurate business category, actual hours, phone, website and service area. Follow Google’s address rules for storefront versus service-area businesses. Ensure the website, Google profile and legitimate business listings describe the same business consistently. Add actual installation photos and request honest reviews from real customers after completed work; respond to them. Use confirmed testimonials on the website with permission.

Local results depend on relevance, distance and prominence. A person searching “CCTV installation near me” will not see identical results in every location. [Google local ranking guidance](https://support.google.com/business/answer/7091?hl=en-en).

## Priority 3 — Create useful CCTV service content

The current sitemap has the homepage, the Digital Seva page and five policy pages. There are no dedicated CCTV installation or CCTV repair service URLs.

Create distinct, useful pages for:

- CCTV installation and packages in Mira-Bhayandar.
- CCTV repair and AMC in Mira-Bhayandar, with real scope and response terms.
- Housing society CCTV installations, with an actual project example when available.

Separate Mira Road or Bhayandar location pages are worthwhile only if they contain genuinely different project evidence and useful local information. Avoid making many near-identical pages that swap place names. Link new pages from the homepage and include their canonical URLs in the sitemap.

Suggested query themes to evaluate in Search Console: “CCTV installation Mira Road,” “CCTV camera installation Bhayandar,” “CCTV repair Mira-Bhayandar,” and “CCTV AMC Mira Road.” These are candidate targets, not verified search-volume or ranking claims.

Suggested homepage title: **CCTV Installation in Mira-Bhayandar | Sarathi Smart Solutions**.

Suggested H1 when deploying the conversion changes: **Reliable CCTV Installation in Mira-Bhayandar. Fast Local Support.** Keep clear service/location wording alongside the stronger conversion message. This improves clarity; it is not a mandatory exact-keyword formula. [Google title guidance](https://developers.google.com/search/docs/appearance/title-link).

## Priority 4 — Improve evidence and mobile speed

Replace the visible customer-feedback placeholder with actual approved feedback. Add two or three real installation stories with property type, locality, equipment, scope, genuine photos and the outcome. Verify that gallery photographs depict the work being claimed before describing them as completed local projects.

The local source gallery has three JPEGs of approximately 591–706 KB each. Optimize these to WebP/AVIF and supply responsive image sizes while retaining explicit dimensions and lazy loading. Confirm actual live image transfer sizes and quality during implementation. No Lighthouse score or field Core Web Vitals result was measured in this audit. Check mobile PageSpeed Insights and Search Console Core Web Vitals before assigning a speed score.

Align the structured business address with the confirmed customer-facing address: visible content includes RNP Park, while structured data currently only gives Bhayander East. Add verified business hours and profile links where appropriate. Do not invent ratings or credentials. [Google local business structured data](https://developers.google.com/search/docs/appearance/structured-data/local-business).

## Lower-priority observations

- The published robots.txt includes Cloudflare rules blocking multiple AI retrieval/training user agents. Googlebot is not listed among those blocked agents. Treat AI retrieval visibility as a separate policy choice; changing it is not required to make this homepage eligible for ordinary Google Search.
- FAQ content is helpful, but FAQ schema is not a shortcut to search visibility. Google’s current changelog says FAQ rich results stopped appearing on 7 May 2026: [Google Search documentation updates](https://developers.google.com/search/updates).
- If the operations Next.js app is deployed as the public website, its default `PUBLIC_SITE_URL` still points to the old Pages address, and its public robots/sitemap files contain build placeholders. Ensure that deployment renders production URLs and serves valid crawl files. This was not observed as a defect on the audited live static site.
- Update sitemap `lastmod` only when a page actually receives a meaningful update; use the real published date for the pending copy/comparison changes.

## Completion criteria

- Search Console confirms the homepage is indexed with the expected canonical, or gives a specific exclusion reason to resolve.
- Sitemap is processed without URL errors.
- Business Profile is verified and accurate.
- Targeted service pages are live, internally linked and indexed where Google chooses to index them.
- Performance reports begin showing relevant local queries; measure enquiry conversions alongside clicks.

This audit created a report only. It did not change live hosting, Search Console, the Google Business Profile, or website copy.
